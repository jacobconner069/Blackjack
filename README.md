Blackjack App

This project creates an app where the user is able to play blackjack against the cpu.

BlackJack.java contains the primary code that controls and creates the playable game.
App.java contains a basic main function to run the app through the BlackJack class.
chips contains .png files for the chip images that are used within the app.
cards contains .png files for the card images that are used within the app.
